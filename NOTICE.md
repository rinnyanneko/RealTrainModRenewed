# Notices and Attribution

RealTrainModRenewed is a modernization fork intended to preserve compatibility
with the RealTrainMod ecosystem while porting the codebase to modern Minecraft
and NeoForge versions.

Unless otherwise noted, this project is licensed under the GNU Lesser General
Public License version 3 or later. See `LICENSE` for the full license text.
Original license notices and copyright notices must be preserved when
redistributing source code or binaries.

## RealTrainMod

RealTrainMod, originally created by NGT5479, is the upstream project and primary
behavioral reference for this fork. RealTrainModRenewed keeps attribution to the
original RealTrainMod project and aims to preserve compatibility with legacy RTM
model packs, scripts, rails, vehicles, signals, and related assets where
practical.

## RealTrainModUnofficial

RealTrainModRenewed is derived from RealTrainModUnofficial, an LGPL-based
modification/fork in the RealTrainMod lineage.

Reference repository:

https://github.com/325-Sunnygo/RealTrainModUnofficial

RealTrainModUnofficial remains the direct source lineage for this modernization
fork and an important reference for legacy behavior, compatibility decisions,
migration history, and attribution. Notices from RTMU and its upstream sources
must be preserved when code or assets derived from that project are retained or
modified.

## KaizPatchX

KaizPatchX is an important compatibility and behavior reference for the modern
RTM ecosystem, especially around legacy compatibility fixes, ATS-related
behavior, WebCTC-related behavior, and expectations from existing RTM packs.

Reference repository:

https://github.com/Kai-Z-JP/KaizPatchX

When functionality is implemented with reference to KaizPatchX behavior, preserve
applicable notices and document material code or asset reuse separately.

## AppleExtended

AppleExtended is an unofficial modification of RTM, NGTLib, and MCTE for legacy
Forge-era RTM environments. RealTrainModRenewed uses it only as a behavioral and
compatibility reference for add-on pack quality-of-life features unless a
specific copied or derived file is documented separately.

Reference repository:

https://github.com/ringo-1234/AppleExtended

When functionality is inspired by AppleExtended behavior, preserve applicable
notices and document material code or asset reuse separately.

## Add-on Packs and Third-Party Assets

RealTrainModRenewed can load legacy RTM/RTMU add-on packs. Those packs are
separate works owned by their respective authors and may have their own license
terms. Compatibility with an add-on pack does not imply that its assets are part
of RealTrainModRenewed or covered by this repository's license.

Bundled or redistributed third-party assets must keep their original notices,
authors, and license information.
